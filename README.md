# Kendall-tau paper reproduction code

This repository contains the publication-only reproduction bundle synchronized
to the September 24, 2026 review PDF of the FSA-KD manuscript. It includes
compact frozen numerical projections and the exact table and figure source
assets, as well as fresh-run implementations.

Start with the manuscript fingerprint and scope notes in
[`paper-reproduction/docs/MANUSCRIPT_REFERENCE.md`](paper-reproduction/docs/MANUSCRIPT_REFERENCE.md),
then follow [`paper-reproduction/README.md`](paper-reproduction/README.md).
Exploratory, superseded, and unreported experiments are intentionally omitted.
