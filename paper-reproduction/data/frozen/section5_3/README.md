# Frozen inputs for Section 5.3

The two application studies reported in Section 5.3 use separate frozen
projections:

- `four_drug/` contains the Experiment 21 parent subset and the compact
  Experiment 30 Mallows-GP results used by Table 2;
- `pcb/` contains the Experiment 24 profiles, seeds, initial designs, exact
  oracle, BO curve, and Table 3 source.

Experiment numbers record computational lineage and should not be interpreted
as manuscript section numbers.
