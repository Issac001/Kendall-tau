# Section 5.3 application case studies

Section 5.3 of the September 24, 2026 review manuscript contains two
application studies. Their code is grouped here accordingly:

- `four_drug/`: the real four-drug order-of-administration study;
- `pcb/`: the mechanism-inspired semi-synthetic PCB benchmark.

The numbered upstream runs remain Experiment 30 and Experiment 24,
respectively. Those experiment identifiers record computational provenance;
they are not manuscript section numbers.

Each subdirectory contains its own run instructions. Frozen inputs use the
matching layout under `data/frozen/section5_3/`.
